## 행정구역 탐색과 거래 집계

2026-09-12 구현. 추가 외부 수집 없이 적재된 매매 실거래와 공식 법정동 마스터를 연결한다.

<a id="region-comparison-사용"></a>

### 사용

- 메뉴 이름은 **동네 탐색**이다. `/explore`의 시·도 → 시·군·구 → 읍·면·동 선택란으로 조회한다. 구 목록을 눌러도 동별 비교로 이동하며, 동 목록을 누르면 그 동의 상세 분석으로 이동한다.
- 상단 지역 경로의 서울특별시를 누르면 전체 구 비교, 구 이름을 누르면 전체 동 비교로 돌아간다. 상위 지역이 바뀌면 하위 선택은 초기화하고 예산·부동산 유형은 유지한다.
- 동 상세는 거래 표본·최근 거래월·평균·중앙값·㎡당 가격 중앙값·예산 내 거래 비중을 제공한다.
- 부동산 유형과 예산을 적용하고 거래량, 중앙값, 사분위 가격 범위, 예산 내 거래 비중을 확인한다. 지역을 케이스에 저장할 수 있다.
- 아파트는 동 선택 → 같은 동의 단지 추천 → 후보 저장으로 이어진다. 나머지 유형은 지역 통계와 관심 지역 저장을 제공한다.
- AI 컨시어지: ‘서울특별시 강남구에서 8억 이하 아파트 매매 가능한 동네를 비교해줘’ → ‘그럼 역삼동은 어때?’처럼 이어 질문한다. `/chat` 법률·세금 안내와는 별도 기능이다.

<a id="region-comparison-집계-계약"></a>

### 집계 계약

`GET /api/market/regions/summary?region_code=1168000000&group_level=eup_myeon_dong&property_type=apartment`

기본 집계 단위는 기존 호환을 위해 `sigungu`를 유지한다. 동 코드를 지정하면 그 동의 통계를 반환한다. 컨시어지는 구를 지정하면 동별로, 시·도를 지정하면 구별로 비교한다. 지역 계층 API는 기존 `eupmyeondong`과 DB 표준 `eup_myeon_dong`을 모두 받는다.

공식 법정동 코드가 있으면 코드로 연결하며, 코드가 없는 거래만 동일 시·군·구 코드와 공백 제거한 정확한 동 이름으로 연결한다. 코드가 있는데 다른 동을 가리키면 이름으로 재매칭하지 않는다. 해제 거래와 기간 밖 거래는 제외한다. 단지 조회에도 같은 동 필터와 해제 거래 제외를 적용한다.

행정동이 아닌 **법정동** 기준이다. 동을 확인할 수 없는 거래는 동별 통계에서 제외되므로 동 통계의 합과 구 전체 거래량은 다를 수 있다. 미집계 동은 거래 0이라고 단정하지 않고 목록에서 제외한다. 현재 적재된 서울 매매 실거래 기준이며 전국·전월세 데이터 제공을 의미하지 않는다. 예산은 거래 비중을 보여주는 조건이며 현재 매물 존재를 보장하지 않는다.

<a id="region-comparison-검증"></a>

### 검증

- 격리 PostgreSQL·Redis 전체 테스트 887개 통과, 고정 입력 평가 33/33 통과. 프론트엔드 타입 검사·린트·프로덕션 빌드 통과.
- `tests/test_concierge_scope.py`: 공식 코드 우선, 코드 없는 이름 매칭, 같은 이름의 다른 구 제외, 해제·유형 필터, 중앙값·예산 비중, 동 저장 시 통계 스냅샷, 단지의 동 범위와 해제 제외, 대화 조건 유지 검증.
- 실제 브라우저: 강남구 선택 → 법정동 14곳 집계 → 역삼동 단지 조회 → 관심 지역 저장 확인. 실제 모델로 구 비교 후 역삼동 후속 질문과 예산 유지 확인.
- `scripts/verify_explore_hierarchy_browser.cjs`: 실제 API와 임시 계정으로 목록·선택란을 통한 서울 → 구 → 동 이동, 상위 경로 복귀, 다른 구 선택 시 동 초기화, 예산·유형 유지, 단지 범위·관심 지역 저장, 모바일 가로 넘침 여부를 검증했다. 실행은 프로젝트 루트에서 `PLAYWRIGHT_MODULE_PATH`(선택)와 `E2E_BASE_URL`(기본 localhost:3001)을 설정하고 Node로 스크립트를 실행한다. Playwright 및 Chrome이 필요하며 임시 계정은 종료 시 삭제한다.
- 실제 DB에서 해제 제외 140,099건 중 140,098건이 동 이름으로 연결됨. 나머지 1건은 구 코드 `11290`과 동 이름 `청량리동`의 불일치로 제외. 원본 거래를 수정하지 않았다.
- 브라우저 근거는 로컬 `evaluation-results/dong-live.json`, `dong-explore.png`. 이는 특정 입력의 동작 검증이며 모든 자연어 표현의 성공이나 시세 정확도를 보장하는 평가가 아니다.

<a id="region-comparison-남은-범위"></a>

### 남은 범위

현재 챗봇 조건은 한 지역 범위다. ‘역삼동과 잠실동만’처럼 서로 다른 구의 임의 동 여러 개를 한 요청으로 지정하는 기능은 별도 확장이 필요하다. 통근·교통·학교·생활시설 기반 추천도 별도 데이터가 필요하다. 지역 통계는 면적·연식 구성을 보정한 AVM 가격이 아닌 신고 실거래의 단순 집계다.
